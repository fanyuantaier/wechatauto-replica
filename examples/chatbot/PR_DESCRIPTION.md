## 摘要

新增 `examples/chatbot/`：基于现有库的独立群聊机器人应用示例，不修改库公共 API、版本或运行默认值。

包含多群/私聊监听、文字聚合、视觉/本地语音/视频处理、发送确认、引用回退、前台恢复、本地记忆与别名、管理员命令、免费网页搜索及单次看门狗。提供本地初始化脚本和空白配置模板。

新增详细中文教程 `TUTORIAL.zh-CN.md`：虚拟环境安装、配置字段、管理员身份与会话标识、默认关闭功能的开启方法、ASR 模型快照下载、贴纸标签、计划任务看门狗及隐私注意事项。

## 隐私与分发范围

- 不包含密钥、真实账号/群/联系人、聊天记录、记忆、发送队列、日志、机器路径、私人人设或历史运行数据。
- 不附带贴纸图片、真实媒体 MD5 映射、模型或依赖二进制。
- 配置及运行数据被 Git 忽略；管理员列表为空，主动发言/自动贴纸/缓存删除等功能关闭。
- 保留上游 Apache-2.0 许可证，独立示例由作者决定是否合并及如何拆分。
